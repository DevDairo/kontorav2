# Bitacora de migracion

## Convenciones

- `OBS`: observacion o riesgo detectado.
- `MOD`: modificacion aplicada.
- `ERR`: error encontrado durante una prueba.
- `VAL`: validacion realizada.
- Estados: `abierto`, `resuelto`, `pendiente`.
